# 中文塔罗牌 WebGL 页面

这是一个无远程依赖的中文塔罗牌抽卡页面。项目扫描阶段没有发现可复用的 `three.module.js`、既有源码或构建配置，因此使用原生 WebGL 1.0 实现同等职责的场景、PBR 近似光照、射线检测和局部高度位移，没有从 CDN 下载运行时依赖。

## 启动

```bash
npm start
```

或：

```bash
python3 -m http.server 4173
```

访问：`http://localhost:4173/`

## 已确认并使用的素材

四个牌位复用当前目录中唯一确认到的完整正面贴图组合：

- 颜色图：`./assets/image(7).png`（750 × 1900）
- 法线图：`./assets/a_stylized_normal_map_image_overall_scene_is_a_hi.png`（843 × 1864）
- 粗糙度图：`./assets/奥黛塔_灰度舞姿与圆环徽章.png`（840 × 1873）
- 高度图：`./assets/需要标题_in_chinese_max_7_words.png`（941 × 1672）
- 固定背景：`./assets/蓝金水幻少女·全身动态立绘.png`（1024 × 1536）

没有扫描到用途能够独立确认的卡背颜色图。页面暂时复用已存在的法线图作为卡背颜色，不生成占位图片；卡背法线、粗糙度、高度则使用运行时创建的 1 × 1 内存中性纹理。

所有项目内素材副本均保持原始字节，未压缩、转换、裁切、重命名或改写。

## 主要实现位置

- `src/assets.js`：素材路径集中映射。
- `src/texture-cache.js`：纹理缓存、加载失败处理和内存中性纹理。
- `src/card.js`：卡牌根位置、倾斜层、翻牌层及状态阻尼。
- `src/shaders.js`：颜色、法线、粗糙度采样，以及高度图驱动的局部顶点位移。
- `src/renderer.js`：WebGL 初始化、高细分网格、灯光、绘制、世界射线与牌面 UV 命中。
- `src/app.js`：布局同步、鼠标/触摸/键盘、洗牌、滚动与生命周期。

## 已知素材限制

- 当前只有一套完整正面 PBR 素材，四个牌位的内部牌序会随机变化，但图像本身看起来相同。
- 没有独立卡背颜色图，当前卡背是对现有素材的临时复用。
- 四类正面贴图的像素尺寸和宽高比不完全一致，统一 UV 采样时细节可能不能逐像素完全对齐。
